The duplicate invoice.

Finance expects R18,500. The migration file says R27,000. Which line would you hold before sign-off?

During an acquisition, two billing extracts can include the same invoice. Adding the exports together overstates receivables. Removing a row on invoice number alone can also erase a legitimate charge. Try the analyst’s review using a fictional batch.

Read the specification and information security scope
Owner
The migration analyst prepares the batch. Finance decides whether the flagged invoice can be held.
Inputs
Two fixed synthetic extracts in ZAR and an independently supplied control total. The fields needed for review are source, invoice, account reference and amount.
Controls
Project each row onto those four fields, dropping the synthetic contact name and email. Flag repeated invoice and account pairs. A reviewer compares the amounts and source before making a decision.
Release rule
Require a human decision. Issue a reconciliation receipt only when the included amounts equal the control total. Retain the held row in the review trail.
Boundary
This exercise uses browser memory and accepts no uploads. Reloading clears the decision. Field removal covers the known sample schema. Account and invoice references remain linkable and would need controlled access in production.
Production scope
Authenticated finance approval, access restrictions, a durable audit trail and a retention policy would be required before using client records. This exercise models the decision only.

Business case

What is the review time worth?

My FinQuery post-migration review went from four hours to 30 minutes. Use that time difference as a scenario for this invoice workflow. The rate, volume and cost below are illustrative. Time saved represents capacity, not cash received.

How the estimate works

Manual effort is 4 hours per run. Assisted effort includes 30 minutes of human review. Annual capacity value equals the hours saved per month × 12 × hourly cost. First-year ROI equals (annual capacity value minus implementation and operating cost) divided by that cost.
